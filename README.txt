ふたり帳 iPhone向け試作品

内容:
- iPhoneの画面サイズとタップ操作に合わせたUI
- ユーザー名設定、記録追加、記録一覧、共有/個人項目、精算表示
- ブラウザ内保存、JSONバックアップ/復元
- PWA用のmanifestとservice workerを同梱

重要:
HTMLを「ファイル」アプリのクイックルックで開いてもJavaScriptはアプリとして動作しません。
Safariで使うには、これらのファイルをHTTPS対応のWebホスティングに公開する必要があります。
公開しても、現在のデータ保存はその端末のブラウザ内だけで、2台間の自動同期はありません。
2台間同期には別途、共有データベースと認証設定が必要です。
